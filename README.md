# VERILOG-4BIT-COUNTER 

## OVERVIEW 
This project implements a 4-bit counter using Verilog HDL. The counter increments on every positive clock edge and the resets to zero when the resetn signal is asserted. 

## FEATURES 
- 4-bit binary counter
- Reset functionality
- Postive edge clock triggering

## COUNTER OPERATION 
0000 -> 0001 -> 0010 ..... -> 1111 -> 0000

## RESET OPERATION 
When reset = 1, the counter becomes 0000 

## TOOLS USED 
- Verilog HDL
- VS code
- Icarus verilog
